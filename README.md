# Caveworld

Ich möchte ein Pixel Art Open World Spiel entwickeln, das in der Steinzeit spielt. Ziel ist es, einen Höhlenmensch-Charakter zu steuern, der durch die Wildnis navigieren kann, in Pixel-Grafik und Top-Down-Perspektive. Das Spiel soll im mobilen Hochformat (Android-optimiert) spielbar sein, mit Touch-Steuerung (virtueller Joystick/D-Pad links, Aktionsbuttons rechts) und Status-HUD oben. Ich habe 8-Wege-Sprites (32x32 Pixel) für den Charakter in allen Himmelsrichtungen angehängt (north, north-east, east, south-east, south, south-west, west, north-west). Bitte binde diese Sprites direkt ein und erstelle eine erste erkundbare Steinzeit-Wildnis mit weicher Kamera und Kollisionen.
